# 核心要点

  • Tokens: Individual elements of the input sequence (e.g., words in a sentence).
  • Embeddings: Vector representations of tokens, capturing semantic information.
  • Attention Weights: Values that determine the importance of each 令牌 relative to others.
  • Just multiply each dimension value of the query with the relevant one of each 令牌 and add the results. You get 1 value per pair of tokens.
  • Moreover, softmax function is used because it accentuates differences due to the exponential part, making easier to detect useful values.
  • Just get each attention weight and multiply it to the related 令牌 dimensions and then sum all the dimensions to get just 1 vector (the context vector)
