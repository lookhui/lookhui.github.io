# 核心要点

  • Also note the default <tenant>.onmicrosoft.com domain: its MX record always points to Exchange Online. If inbound to *.onmicrosoft.com is not locked down, sending to user@<tenant>.onmicrosoft.com may land directly in the inbox while bypassing the SEG.
  • You should also try to send different contents because you can find more interesting information on the headers like: X-Virus-Scanned: by av.domain.com\
  • Detecting the AV may allow you to 利用 known vulnerabilities.
  • If the server supports NTLM auth (Windows) you can obtain sensitive info (versions). More info here.
  • Or automate this with nmap plugin smtp-ntlm-info.nse
  • Check if you sniff some 密码 from the packets to port 25
  • Attacker abuse
  • Attackers can craft borderline-aligned campaigns that pass weaker DMARC configurations more often.
  • Whether STARTTLS negotiation works and certificates validate
  • Active network attackers can intercept/modify SMTP traffic more easily if STARTTLS is absent or misconfigured.
  • Downgrade/MITM opportunities increase when policy hosts or MX matching are misconfigured.
  • Increases exposed attack surface and can enable weak-client/legacy downgrade paths.
  • Autodiscover abuse and credential-harvest workflows become easier when plaintext or weak redirects are accepted.
  • https://github.com/serain/mailspoof Check for SPF and DMARC misconfigurations
