# 核心要点

  • Deserialization, conversely, is the process that counteracts serialization. It involves taking data that has been structured in a specific format and reconstructing it back into an object.
  • Deserialization can be dangerous because it potentially allows attackers to manipulate the serialized data to execute harmful code or cause unexpected behavior in the application during the object reconstruction process.
  • toString: This method allows an object to be treated as a string. It can be used for reading a file or other tasks based on the function calls within it, effectively providing a textual representation of the object.
  • If allowed classes is omitted or the code runs on PHP < 7.0, the call becomes dangerous as an attacker can craft a 载荷 that abuses magic methods such as wakeup () or destruct () to achieve Remote Code Execution (RCE).
