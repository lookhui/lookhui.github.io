# 核心要点

  • Access the interpreter shell
  • During boot, hit a known break key (often any key, 0, space, or a board-specific "magic" sequence) before bootcmd executes to drop to the U-Boot prompt.
  • Modify boot arguments to get a root shell
  • Append init=/bin/sh so the kernel drops to a shell instead of normal init:
  • If env storage isn’t write-protected, you can persist control:
  • Check for variables like bootcount, bootlimit, altbootcmd, boot targets that influence fallback paths. Misconfigured values can grant repeated breaks into the shell.
  • Absence of CONFIG FIT SIGNATURE/CONFIG (SPL) FIT SIGNATURE or legacy verify=n behavior often allows booting arbitrary 载荷.
  • Also validate if PXE filename fields are passed to shell/loader logic without sanitization when chained to OS-side provisioning scripts.
  • NXP i.MX (Serial 下载 Mode)
  • Example: sunxi-fel -v uboot u-boot-sunxi-with-spl.bin or sunxi-fel write 0x4A000000 u-boot-sunxi-with-spl.bin; sunxi-fel exe 0x4A000000.
  • Example: rkdeveloptool db loader.bin; rkdeveloptool ul u-boot.bin to stage a loader and 上传 a custom U-Boot.
  • Try booting with downgraded or known-vulnerable signed boot components if Secure Boot revocations (dbx) aren’t current. If the platform still trusts old shims/bootmanagers, you can often load your own kernel or grub.cfg from the ESP to gain 持久化.
