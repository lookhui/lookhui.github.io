# 核心要点

  • Some ideas to try to 绕过 firewalls
  • If you can inject code into a process that is allowed to connect to any server you could 绕过 the firewall protections:
  • Before macOS 11.2 the ContentFilterExclusionList allowed ~50 Apple binaries such as nsurlsessiond and the App Store to 绕过 all socket-filter firewalls implemented with the Network Extension framework (LuLu, Little Snitch, etc.).
  • Malware could simply spawn an excluded process—or inject code into it—and tunnel its own traffic over the already-allowed socket. Apple completely removed the exclusion list in macOS 11.2, but the technique is still relevant on systems that cannot be upgraded.
