# 核心要点

  • Look for exported activities in the Android manifest (an activity with an intent-filter is exported by default). If an exported activity is protected by a permission, the attacking app will need the same permission, which limits exploitability.
  • Check the minimum SDK version android:minSdkVersion in AndroidManifest.xml. If it is lower than 30, older default behaviors may make tapjacking easier to 利用.
  • Trusted windows (accessibility, IME, assistant) still receive events. Invisible or fully transparent overlays also 绕过 the block, which attackers try to abuse by keeping alpha < 0.8.
  • Partial overlays that leave the target area visible are not auto-blocked. Mitigate in sensitive views by rejecting events with the FLAG WINDOW IS PARTIALLY OBSCURED flag:
  • The attribute setFilterTouchesWhenObscured set to true can also prevent the 利用 of this 漏洞 if the Android version is lower.\
  • The most recent Android application performing a Tapjacking attack (+ invoking before an exported activity of the attacked application) can be found in: https://github.com/carlospolop/Tapjacking-ExportedActivity.
  • Hidden-VNC banking RATs briefly display phishing overlays to capture 凭据，then rely on covert VNC plus Accessibility to replay taps with fewer on-device artifacts.
  • 下载 an HTML/JS overlay template from the C2 that perfectly imitates that specific application (Logo, colours, i18n strings…).
  • Display the overlay, harvest 凭据 / PIN/pattern.
  • Audit the list of installed apps with adb shell pm list packages -3 -e BIND ACCESSIBILITY SERVICE.
