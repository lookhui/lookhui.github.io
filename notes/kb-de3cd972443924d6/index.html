# 核心要点

  • Settings of the renderer process can be configured in the main process inside the main.js file. Some of the configurations will prevent the Electron application to get RCE or other vulnerabilities if the settings are correctly configured.

  • Disabling contextIsolation enables the use of <webview> tags, similar to <iframe>, for reading and exfiltrating local files. An example provided demonstrates how to 利用 this 漏洞 to read the contents of internal files:
  • app.importCertificate(options, callback)
  • Imports a PKCS#12 certificate into the system’s certificate store (Linux only). A callback can be used to handle the result.
  • First XSS via webview CSP: The generated CSP included style-src'self' 'unsafe-inline', allowing inline/style-based injection in a vscode-webview://context. The 载荷 beaconed to /stealID to exfiltrate the target webview’s extensionId.
  • Second XSS via postMessage trust: The outer webview trusted window.postMessage without strict origin/type checks and loaded attacker HTML with allowScripts: true.
  • Local file loading via scheme/path rewriting: The 载荷 rewrote file:///... to vscode-file://vscode-app/... and swapped 利用.md for RCE.html, abusing weak path validation to load a privileged local resource.
  • RCE in Node-enabled context: The loaded HTML executed with Node APIs available, yielding OS command execution.
