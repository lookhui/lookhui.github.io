# 核心要点

  • Note that entitlements starting with com.apple are not available to third-parties, only Apple can grant them... Or if you are using an enterprise certificate you could create your own entitlements starting with com.apple actually and 绕过 protections based on this.
  • The entitlement com.apple.rootless.install.heritable allows to 绕过 SIP. Check this for more info.
  • The entitlement com.apple.rootless.install allows to 绕过 SIP. Check this for more info.
  • This entitlement allows to load frameworks, plug-ins, or libraries without being either signed by Apple or signed with the same Team ID as the main executable, so an attacker could abuse some arbitrary library load to inject code. Check this for more info.
  • These entitlements allows to install software without asking for permissions to the user, which can be helpful for a 权限提升.
  • The entitlement com.apple.private.icloud-account-access it's possible to communicate with com.apple.iCloudHelper XPC service which will provide iCloud tokens.
  • Kernel attack surface via malformed IOConnectCallMethod calls
  • USB device spoofing (emulate keyboard for HID injection)
  • DMA attacks through PCIe/Thunderbolt interfaces
