# 核心要点

  • An XML 外部实体 XXE attack is a type of attack against an application that parses XML input and allows XML entities. XML entities can be used to tell the XML parser to fetch specific content on the server.
  • staaldraad/xxeftp：A mini webserver with FTP support for XXE 载荷
  • lc/230-OOB：An Out-of-Band XXE server for retrieving file contents over FTP and 载荷 generation via http://XXE.sh/
  • enjoiz/XXEinjector：Tool for automatic 利用 of XXE 漏洞 using direct and different out of band methods
  • BuffaloWill/oxml XXE：A tool for embedding XXE/XML exploits into different filetypes (DOCX/XLSX/PPTX, ODT/ODG/ODP/ODS, SVG, XML, PDF, JPG, GIF)
  • whitel1st/docem：Utility to embed XXE and XSS 载荷 in docx,odt,pptx,etc
  • GoSecure/dtd-finder：List DTDs and generate XXE 载荷 using those local DTDs.
  • 载荷 to trigger the XXE:
  • Reading Byte Order Mark (BOM)
  • Reading first symbols of document
  • Example: We can convert the 载荷 to UTF-16 using iconv to 绕过 some WAF:
