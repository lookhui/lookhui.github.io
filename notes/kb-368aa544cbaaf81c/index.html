# 核心要点

  • 绕过 of SOP: Scripts are exempt from the Same-Origin Policy, allowing them to be included across domains.
  • Data Exposure: An attacker can 利用 this behavior to read data loaded via the script tag.
  • 认证 令牌 Leakage: If an attacker can trick a user's browser into requesting a script from a server they control, they might be able to access sensitive information contained in these requests.
  • Non-JavaScript：Refers to vulnerabilities that do not involve JavaScript directly.
  • Further details on attack vectors can be found in the work of Security Researcher Sebastian Lekies, who maintains a list of vectors.
