# 核心要点

  • Input (Tokenized Text): The process begins with tokenized text, which is converted into numerical representations.
  • 令牌 Embedding and Positional Embedding Layer: The tokenized text is passed through a 令牌 embedding layer and a positional embedding layer, which captures the position of tokens in a sequence, critical for understanding word order.
  • Feed Forward Layer: Responsible for processing the information from the attention layer and making predictions about the next 令牌.
  • This was already explained in an earlier section.
  • Multi-Head Self-Attention: Allows the model to focus on different positions within the input sequence when encoding a 令牌.
  • Masking: A causal mask is applied to prevent the model from attending to future tokens (important for autoregressive models like GPT).
  • 令牌 Embeddings (tok emb): Converts 令牌 indices into embeddings. As reminder, these are the weights given to each dimension of each 令牌 in the vocabulary.
  • Positional Embeddings (pos emb): Adds positional information to the embeddings to capture the order of tokens. As reminder, these are the weights given to 令牌 according to it's position in the text.
