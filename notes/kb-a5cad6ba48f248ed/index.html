# 核心要点

  • Use this script to 下载 and merge all the yara malware rules from github: https://gist.github.com/andreafortuna/29c6ea48adf3d45a979a78763cdc7ce9\
  • Create the rules directory and execute it. This will create a file called malware rules.yar which contains all the yara rules for malware.
  • Capa detects potentially malicious capabilities in executables: PE, ELF, .NET. So it will find things such as Att&ck tactics, or suspicious capabilities such as:
  • Loki is a scanner for Simple Indicators of Compromise.\
  • 检测 is based on four 检测 methods:
  • DiE is a tool to detect if a file is encrypted and also find packers.
  • NeoPI is a Python script that uses a variety of statistical methods to detect obfuscated and encrypted content within text/script files. The intended purpose of NeoPI is to aid in the 检测 of hidden web shell code.
  • PHP-malware-finder does its very best to detect obfuscated/dodgy code as well as files using PHP functions often used in malwares/webshells.
  • Run angr (CPython3) to execute the decoder for each target string and dump results.
  • Annotate in Ghidra: auto-comment decoded strings at each call site for fast JNI reconstruction.
  • Since angr requires CPython3, keep deobfuscation and annotation separated. First run the angr script above to produce decoded strings.json. Then run this Jython GhidraScript to write PRE COMMENTs at each call site (and include the caller function name for context):
  • Use currentProgram.getReferenceManager() to enumerate call-xrefs even if the app wraps the decoder behind thin stubs.
  • Enables string-cross-reference & xrefs, making behaviour reconstruction trivial.
  • schtasks 枚举: schtasks /query/fo LIST /v | findstr /i "IoKlTr hwpviewer"
