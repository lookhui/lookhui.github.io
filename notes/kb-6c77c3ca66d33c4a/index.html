# 渗透测试闭环方法论

# 提炼原则

  • 范围确认：把域名、IP、账号、云项目、内网段、应用和禁止动作写成清单。
  • 资产收敛：先被动聚合，再用轻量主动验证；只把可访问、可截图、可指纹化的入口进入漏洞验证。
  • 入口验证：每个入口只证明一个最小可控点，例如参数可控、服务版本可控、身份边界可控。
  • 影响扩大：从读取、写入、执行、身份提升、横向移动五类影响中选择副作用最小的一类验证。
  • 证据沉淀：命令、请求、响应摘要、时间、目标、输出判断必须一起记录。
  • 清理与复盘：回滚临时账号、文件、计划任务、规则；把失败条件也写入主题页，减少重复试错。
