# 核心要点

  • Extract tables from Injection database
  • In a time-based blind SQL 注入 attack, an attacker injects a 载荷 that uses WAITFOR DELAY to make the database pause for a certain period. The attacker then observes the response time to infer whether the injected 载荷 executed successfully or not.
  • xp cmdshell is a system stored procedure in Microsoft SQL Server that allows you to run operating system commands directly from within T-SQL (Transact-SQL).
  • If you need to reactivate xp cmdshell, it is disabled by default in SQL Server 2005.
  • Executed by a different user than the one using xp cmdshell to execute commands
  • MSSQL supports stacked queries so we can create a variable pointing to our IP address then use the xp dirtree function to list the files in our SMB share and grab the NTLMv2 哈希.
  • Execute query through the link
  • Execute shell commands
