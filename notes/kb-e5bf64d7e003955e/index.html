# 核心要点

  • SQLmap is a powerful tool that automates the 检测 and 利用 of SQL 注入 vulnerabilities, saving time and effort compared to manual testing. It supports a wide range of databases and injection techniques, making it versatile and effective in various scenarios.
  • Additionally, SQLmap can retrieve data, manipulate databases, and even execute commands, providing a robust set of features for penetration testers and security analysts.
  • A request file in SQLmap is a saved HTTP request that SQLmap reads and uses to perform SQL 注入 testing. This file allows you to provide a complete and custom HTTP request, which SQLmap can use to target more complex applications.
  • A custom injection point in SQLmap allows you to specify exactly where and how SQLmap should attempt to inject 载荷 into a request. This is useful when dealing with more complex or non-standard injection scenarios that SQLmap may not detect automatically.
  • By defining a custom injection point with the wildcard character '*' , you have finer control over the testing process, ensuring SQLmap targets specific parts of the request you suspect to be vulnerable.
  • A second-order SQL 注入 occurs when malicious SQL code injected into an application is not executed immediately but is instead stored in the database and later used in another SQL query.
  • --suffix=SUFFIX: The --suffix option appends a specified string to the end of each 载荷 generated by SQLMap.
  • --prefix=PREFIX: The --prefix option prepends a specified string to the beginning of each 载荷 generated by SQLMap.
  • tamper (载荷): The main function that modifies the 载荷.
  • 令牌 generation: For handling CSRF tokens or dynamic auth headers.
  • The --technique argument defines which SQL 注入 methods sqlmap will attempt.
  • luanginxmore generates ~4.2M random POST parameters before your 载荷；use it only with --method=POST and expect large request sizes to crash poorly configured Lua-Nginx WAFs.
  • 利用 sqlmap 的合法功能完成 inherit 等操作；重点关注 sudo、SUID、受限 shell 与文件读写上下文。
