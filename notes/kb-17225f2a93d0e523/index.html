  • decrypt ($ 载荷，$unserialize=true) will automatically unserialize() the decrypted value.
  • Therefore any attacker that knows the 32-byte secret APP KEY can craft an encrypted PHP serialized object and gain RCE via magic methods ( wakeup, destruct, …).
  • Inject the produced string into any vulnerable decrypt() sink (route param, cookie, session, …).
  • The script transparently supports both CBC and GCM 载荷 and re-generates the HMAC/tag field.
