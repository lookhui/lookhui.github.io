# 原生工具利用与检测方法论

# 提炼原则

  • 先判断上下文：普通用户、sudo、SUID、受限 shell、服务账户、计划任务、EDR 监控各自影响可用命令。
  • 把能力归类：执行、文件读、文件写、下载、上传、反弹 shell、代理、凭据、规避、持久化。
  • 优先使用最短命令验证能力，不直接落地高风险载荷。
  • 检测线索与命令同等重要：父子进程、命令行、网络目的地、写入路径、加载 DLL、事件日志。
  • Windows 原生工具重进程链，Linux 原生工具重权限位、环境变量、路径劫持和解释器逃逸。
  • 主题页中保留命令，但实验记录要补目标环境、版本、权限和失败原因。
