# 核心要点

  • The goal of this third phase is very simple: Assign each of the previous tokens in the vocabulary a vector of the desired dimensions to train the model. Each word in the vocabulary will a point in a space of X dimensions.\
  • Moreover, during the 令牌 embedding another layer of embeddings is created which represents (in this case) the absolute possition of the word in the training sentence. This way a word in different positions in the sentence will have a different representation (meaning).
  • Vocabulary Size: The total number of unique tokens (e.g., words, subwords) in the model’s vocabulary.
  • Embedding Dimensions: The number of numerical values (dimensions) in each 令牌’s vector. Higher dimensions can capture more nuanced information but require more computational resources.
  • Vocabulary Size: 6 tokens [1, 2, 3, 4, 5, 6]
  • At the start of training, 令牌 embeddings are typically initialized with small random values. These initial values are adjusted (fine-tuned) during training to better represent the tokens' meanings based on the training data.
  • Each row corresponds to a 令牌 in the vocabulary.
  • For example, the 令牌 at index 3 has an embedding vector [-0.4015, 0.9666, -1.1481].
  • Accessing a 令牌’s Embedding:
  • The 令牌 at index 3 is represented by the vector [-0.4015, 0.9666, -1.1481].
  • These values are trainable parameters that the model will adjust during training to better represent the 令牌's context and meaning.
  • Max Sequence Length: 4 (number of tokens per sample)
  • Each 令牌 in the sequence is represented by a 256-dimensional vector.
  • 令牌 Order Matters: In sentences, the meaning often depends on the order of words. For example, "The cat sat on the mat" vs. "The mat sat on the cat."
