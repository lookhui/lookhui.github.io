# 核心要点

  • Magic hashes arise due to a quirk in PHP's type juggling, when comparing string hashes to integers. If a string 哈希 starts with "0e" followed by only numbers, PHP interprets this as scientific notation and the 哈希 is treated as a float in comparison operations.
  • The 漏洞 in the following code lies in the use of a loose comparison (!=) to validate the $cookie ['hmac'] against the calculated $ 哈希.
  • $hmac：the provided 哈希，"0"
  • The 利用 phase is the following:
  • Prepare a malicious cookie: The attacker prepares a cookie with $username set to the user they wish to impersonate (for example, "admin"), $expiration set to a future UNIX timestamp, and $hmac set to "0".
