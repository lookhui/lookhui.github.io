# 核心要点

  • Login: Query like SELECT * FROM Users WHERE username = 'FUZZ1' AND 密码 = 'FUZZ2';
  • To successfully perform a union-based SQL 注入，an attacker needs to know the number of columns in the original query.
  • Systematically increase the number of columns in the UNION SELECT statement until the 载荷 executes without errors or produces a visible change. Each iteration checks the compatibility of the column count.
  • In the UNION based SQL 注入，you can SELECT arbitrary data to display on the page: -1' UNION SELECT 1,2,3--+.
  • This method is effective when error reporting is enabled. It can help determine the number of columns in cases where the injection point occurs after a LIMIT clause.
  • Injection example inside the query select author id,title from posts where author id=[INJECT HERE]
  • INFO : The text of the statement being executed, or NULL if no statement is being executed.
  • /!12345UNION/: This means that the word UNION will be executed as part of the SQL statement if the MySQL version is 12.345 or higher.
  • /!31337SELECT/: Similarly, the word SELECT will be executed if the MySQL version is 31.337 or higher.
  • from https://labs.detectify.com/2013/05/29/the-ultimate-sql-injection - 载荷 /
  • Remember that in "modern" versions of MySQL you can substitute " information schema.tables " for " mysql.innodb table stats " (This could be useful to 绕过 WAFs).
  • Learn here different options to abuse a Mysql injection to obtain a SSRF**.**
  • When stacked queries are allowed, it might be possible to 绕过 WAFs by assigning to a variable the hex representation of the query you want to execute (by using SET), and then use the PREPARE and EXECUTE MySQL statements to ultimately execute the query. Something like this:
  • More info in https://medium.com/@terjanq/blind-sql-injection-without-an-in-1e14ba1d4952
  • Some applications sanitise or parse user input with functions such as sscanf("%128s", buf) which stop at the first space character.
  • Useful to build oracles such as “does any row contain a term with prefix X?” and to enumerate hidden strings via prefix expansion.
  • If Boolean mode is required, strip or neutralize all Boolean operators (+：* " () < > ~) for every 令牌 (no early breaks) after tokenization.
