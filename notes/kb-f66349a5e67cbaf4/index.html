# 核心要点

  • Uploaded files go to: http://10.10.10.10/wp-content/uploads/2018/08/a.txt
  • In wp-config.php you can find the root 密码 of the database.
  • wp-content/uploads/ Is the directory where any files uploaded to the platform are stored.
  • wp-includes/ This is the directory where core files are stored, such as certificates, fonts, JavaScript files, and widgets.
  • 后渗透
  • Contributor: Write and manage his posts but cannot publish them
  • Login username 枚举: When login in /wp-login.php the message is different is the indicated username exists or not.
  • 凭据 Bruteforce
  • wp.getUserBlogs, wp.getCategories or metaWeblog.getUsersBlogs are some of the methods that can be used to brute-force 凭据. If you can find any of them you can send something like:
  • DDoS or port scanning
  • Modifying a php from the theme used (admin 凭据 needed)
  • Navigate to the WordPress dashboard, then go to Dashboard > Plugins > 上传 Plugin.
  • 上传 the zip file of the downloaded plugin.
  • With the plugin "reflex-gallery" installed and activated, it can be exploited as it is known to be vulnerable.
