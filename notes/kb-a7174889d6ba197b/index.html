# 知识库扩展规范

# 提炼原则

  • 新增内容必须先提炼：不要复制原 README、构建说明、图片、安装脚本或站点目录。
  • 一页只解决一个知识点：标题用中文可查名称，英文术语放 aliases。
  • 命令必须配上下文：前置条件、目标、输出判断、检测线索和副作用。
  • 重复主题先合并：同一漏洞、工具或技巧只保留一个主笔记，差异写在扩展记录。
  • 图谱靠 Hub 连接：新专题应链接到领域总览、知识地图和至少一个 Hub。
  • 定期跑检查：未解析链接、误入构建文件、空要点主题、孤立笔记都要修复。
